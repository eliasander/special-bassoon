# Running Gravity

## Company Description

We offer a selection of luxury mansions with amazing locations. Our target audience is
men. We want to convey a sense of importance, while at the same time being agreeable.

## Job Description

You must create a website that will mainly provide information. The goal is to make a
landing page that maximizes conversions. Besides the landing page, the website will
need a information page, shop page and a privacy policy page. The landing page should
have a About the Team section. There should be a call to action to get users to make a
purchase. They would prefer a trendy design, and would like you to use the brand color,
which is black. Take into account the client's preferences and values.
